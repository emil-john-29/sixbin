# SixBin – Online-Inhalte

Dieses Repository liefert die Inhalte der App **SixBin** (inoffizielle Fan-App zu GTA VI) aus.

- `content.json` – alle Cheats, Tipps, News und Datenbank-Einträge. Die App lädt diese Datei live.
- `index.html`, `datenschutz.html`, `impressum.html`, `hinweise.html` – Webseite & Rechtliches (für den App Store).
- `RECHERCHE.md` – Regeln für die automatische Recherche.
- `tools/validate.py` – prüft `content.json` vor jeder Veröffentlichung.

Veröffentlicht über GitHub Pages.
